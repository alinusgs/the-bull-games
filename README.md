# The Бык — Игровая зона

Три мини-игры для гостей заведения. Гость сканирует QR, выбирает игру, за 3 минуты набирает очки и получает промокод.

Маскот The Бык реализован как процедурная 3D-модель Three.js без использования фотографии в игровых сценах.

## Локально

```bash
python3 -m http.server 8000
```

Открыть `http://localhost:8000/`.
