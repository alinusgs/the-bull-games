# The Бык — автономная игровая зона

Публичный GitHub Pages проект без CDN и внешних библиотек.

Файлы в корне репозитория:
- index.html
- mascot3d.js
- games/
- assets/qr.png

3D-маскот строится процедурно в браузере из объёмных 3D-примитивов и анимируется. Фото маскота не используется как игровой спрайт.
